# KanhaERP — User Guide (simple)

Hindi + English mixed — office staff ke liye.

## Browser open

`http://127.0.0.1:8080`

## Login

1. Apna role icon tap karo (Admin / Sales / Accounts)
2. Password dalein
3. **Enter workspace**

| Role | Email | Password |
|------|--------|----------|
| Admin | admin@kanhaerp.com | admin123 |
| Sales | sales@kanhaerp.com | sales123 |
| Accounts | accounts@kanhaerp.com | accounts123 |

**Other email account** button se koi aur email se bhi login ho sakta hai.

## Password bhool gaye?

Owner se bolo — login page pe **◉** Ultra Support.

## Main buttons

- **Start Live Flow** — Lead se Invoice tak guided path
- **Approvals** — pending approvals + emergency bypass (policy ke hisaab se)
- **Agents** — cash / stock / compliance helpers
- Bottom-right **CORE** — ERP help AI (personal details nahi maangta)
- Owner only **◉** — Core Control (repair, not delete)
